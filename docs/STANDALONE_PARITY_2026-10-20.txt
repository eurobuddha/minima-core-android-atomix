Behavior
Node-derived ETH keys require a Boolean success envelope, exactly 32 hex bytes and
a valid nonzero secp256k1 scalar. Failed responses never replace current credentials;
error messages do not echo secret response data. Probes cannot replace the wallet.
Market drafts reject malformed, underflowed and overflowing numbers before row
replacement or persistence. Invalid Save leaves the editor open. Swap quotes require
finite positive amounts at the existing six-decimal settlement grain; invalid
slippage stays editable. Sweep planning rejects invalid totals/quotes/caps.
Interrupted-write acknowledgement captures the reviewed node and marker. A different
marker or active write cannot be cleared by stale consent. Failed persistence restores
marker details and keeps a process latch against new writes until acknowledged.
OTC input parsing rejects nonfinite sizes/terms before preference changes, funding
review or publication. Unsaved availability values survive refresh; focus guards
avoid rebuilding the form while typing. Currency switching already recreates the
Activity, so drafts do not carry into a different currency. Existing OTC controllers,
swap engine and transaction journal were not rewritten.
